# پورتفولیو اختصاصی حبیب اقدامی (Habib Eghdami Portfolio)

یک وب‌سایت پورتفولیو با استایل بصری دارک/سایبرپانک (Cyber Editorial)، الهام‌گرفته از دیزاین فتوشاپ شما با بالاترین استانداردهای مهندسی وب، سرعت بافرینگ ویدیو و بهینه‌سازی لایت‌هاوس.

---

## 🚀 ویژگی‌های کلیدی و بهینه‌سازی‌ها

1. **مدیریت هوشمند بافرینگ ویدیو (Zero Buffering Lag):**
   - برای هر ویدیو یک تصویر پوستر (Poster) باکیفیت و کم‌حجم لود می‌شود تا در لحظه اول لود سایت هیچ لگی حس نشود.
   - سورس ویدیوها با استفاده از `IntersectionObserver` فقط زمانی لود می‌شود که کاربر به نزدیکی آن بخش اسکرول کند (`preload="none"` تا مصرف اینترنت و پردازنده بهینه بماند).
   - با رفتن ماوس روی هر کارت (Hover)، پیش‌نمایش ویدیو بی‌صدا و نرم پخش می‌شود. با کنار رفتن ماوس، ویدیو متوقف می‌شود.
   - با کلیک روی هر کارت، **حالت تئاتر (Theater Lightbox Modal)** باز می‌شود که ویدیو را با کیفیت اصلی، کنترل‌های کامل و صدا پخش می‌کند.

2. **طراحی بصری برنده جایزه (Award-Winning Cyber Aesthetic):**
   - تم مشکی و قرمز نئونی عمیق با Ambient Mesh Glows
   - فریم هدف‌گیری سایبرپانک (HUD Viewfinder) دور تصویر پروفایل با انیمیشن اسکنر نوری و نشانگر ماوس `CREATIVE DESIGNER`
   - افکت شیب سه‌بعدی تعاملی (3D Parallax Tilt) هنگام حرکت ماوس
   - گرادیان شیشه‌ای (Glassmorphism) با بلور ۲۰ پیکسل
   - تایپوگرافی واترمارک بزرگ در پس‌زمینه

3. **تب فیلتر دسته‌بندی پروژه‌ها:**
   - فیلتر آنی بین: **همه پروژه‌ها**، **ویدیو و تیزر**، **پوستر و کی‌ویژوال**، **استوری و ریلز (9:16)** و **تبلیغات شهری** بدون ری‌لود صفحه.

4. **بخش تماس تعاملی و حرفه‌ای:**
   - دکمه کپی شماره تماس با ۱ کلیک (`۰۹۱۲۶۷۱۷۲۵۵`) و اعلان Toast
   - دکمه‌های مستقیم تماس تلفنی، چت واتس‌اپ، تلگرام و اینستاگرام

## 📂 ساختار فایل‌ها و پوشه‌ها

```
portfolio/
├── index.html                 # ساختار کامل نسخه فارسی (RTL) با فونت‌های مانلی و رخ
├── index-en.html              # نسخه کامل انگلیسی (LTR) با زبان بین‌المللی و تایپوگرافی مدرن
├── styles.css                 # استایل‌های مدرن با سیستم تایپوگرافی دو زبانه و انیمیشن‌ها
├── app.js                     # موتور تعاملی، بافرینگ هوشمند ویدیوها، لایت‌باکس و کپی دو زبانه
├── assets/
│   ├── fonts/                 # فونت‌های اختصاصی مانلی (Maneli) و تمامی وزن‌های رخ (Rokh)
│   ├── videos/                # محل قرار دادن ویدیوهای MP4 پروژه‌ها
│   │   ├── motorsport.mp4
│   │   └── story.mp4
│   └── images/                # پوسترهای باکیفیت و تصاویر پروژه‌ها
└── public/
    └── assets/                # تصاویر مسکات سه‌بعدی و است‌های رسانه‌ای
        ├── mascot_hero.jpg    # کاراکتر سه‌بعدی دیزاینر در هدر اصلی
        └── mascot_contact.jpg # کاراکتر سه‌بعدی با زاویه تعاملی در فوتر
```

## 🎬 چطور ویدیوها و پوسترهای خود را جایگزین کنید؟

کافیست فایل ویدیویی خود را داخل پوشه `assets/videos/` بگذارید و در فایل `index.html`، آدرس را داخل تگ کارت پروژه بنویسید:

```html
<article class="project-card video-card" 
  data-category="video" 
  data-title="نام پروژه شما" 
  data-client="نام کارفرما" 
  data-type="video" 
  data-video="assets/videos/your-video.mp4">
  
  <div class="card-media-wrapper">
    <img src="assets/images/your-poster.jpg" alt="پوستر" class="card-poster">
    <video class="card-video" loop muted playsinline preload="none" data-src="assets/videos/your-video.mp4"></video>
  </div>
  ...
</article>
```
